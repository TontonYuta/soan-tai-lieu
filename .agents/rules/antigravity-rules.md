# Quy Tắc Vận Hành Antigravity Agent Trong YutaLatexMath Studio

- **Không Yêu Cầu API Key**: Antigravity Agent chạy local trực tiếp qua `agy -p`.
- **Định Dạng Xuất Toán Học**:
  - Dành cho tài liệu LaTeX: Xuất mã khối `\documentclass...` đầy đủ và tương thích gói `vietnam`.
  - Dành cho Video Manim CE: BẮT BUỘC có `from manim import *`, class `MainScene(Scene)` và `def construct(self):`.
- **Dọn Dẹp Tài Nguyên**: Tự động dọn dẹp file trung gian sau khi hoàn tất xuất bản.
