## 🌟 Tính Năng Nổi Bật

### 1. 🎓 Đề Thi Chuẩn Hóa 2025–2026 (Exam Studio)
- **Chuẩn format 3 Phần của Bộ GD&ĐT (Áp dụng cho kỳ thi TN THPT, HSA, V-SAT):**
  - **Phần I:** Câu hỏi trắc nghiệm nhiều phương án lựa chọn ($A, B, C, D$).
  - **Phần II:** Câu hỏi trắc nghiệm Đúng / Sai (Mỗi câu gồm 4 mệnh đề $a, b, c, d$ để học sinh đánh giá).
  - **Phần III:** Câu hỏi trắc nghiệm Trả lời ngắn (Tự tính toán và điền đáp số).
  - **Đề thi truyền thống:** Trắc nghiệm nhiều lựa chọn + Tự luận kèm dòng kẻ làm bài.
- **Tích hợp Vẽ Hình & Đồ Thị TikZ/pgfplots tự động:**
  - Tự động vẽ hình học không gian (khối chóp, lăng trụ, nón, trụ, cầu, góc & khoảng cách, hệ tọa độ $Oxyz$).
  - Tự động dựng Bảng biến thiên (BBT) và Đồ thị hàm số chuẩn xác.
- **Phân bổ ma trận 4 mức độ:** Nhận biết (NB) $\to$ Thông hiểu (TH) $\to$ Vận dụng (VD) $\to$ Vận dụng cao (VDC).
- **Bộ Preset thiết lập 1-chạm:** Đề 90 phút (12+4+6), Đề 45 phút, Đề 15 phút.

### 2. ✨ Bài Tập Tương Tự & Đổi Số (Similar Exercises)
- Dán 1 bài toán mẫu bất kỳ $\to$ AI tự động phân tích dạng toán cốt lõi.
- Tự động sinh từ 1 đến 10 bài toán tương tự cùng dạng hoặc tăng/giảm độ khó (Dễ hơn / Tương đương / Nâng cao).
- Tự động tính toán số liệu nghiệm đẹp, bảo đảm logic toán học và xuất kèm lời giải chi tiết từng bước.

### 3. 📝 Phiếu Bài Tập In Ấn (Worksheet Generator)
- Thiết kế tài liệu học tập in ấn đẹp mắt theo phong cách chuẩn pdfLaTeX.
- Tích hợp macro dòng kẻ chấm (`\dongke`) giúp học sinh làm bài và ghi chép trực tiếp.
- Phân chia rõ ràng: *Lý thuyết trọng tâm $\to$ Ví dụ mẫu $\to$ Bài tập trắc nghiệm $\to$ Bài tập tự luận $\to$ Bảng đáp án*.

### 4. 📖 Bài Học Lý Thuyết (Learning Lecture)
- Biên soạn bài giảng sư phạm chuyên sâu từ định nghĩa, tính chất, chứng minh đến công thức giải nhanh.
- Đóng khung công thức quan trọng bằng `tcolorbox` vuông vức phong cách hiện đại.

### 5. 🗺️ Lộ Trình Học Tập (Roadmap A–Z)
- Xây dựng bản đồ học tập từ mất gốc đến điểm 8+, 9+ theo từng tuần, từng chặng rõ ràng kèm tiêu chí đánh giá (checkpoint).

### 6. 🎬 Video & Manim Animation Studio
- **Đính Kèm Tài Liệu PDF (RAG Video):** Tải lên đề thi, bài tập hoặc sách giáo khoa PDF $\to$ AI tự động trích xuất bài toán, hàm số, hình vẽ để dựng kịch bản và mã Manim bám sát tài liệu.
- **Kịch bản Lời Thoại Phân Cảnh (Storyboard Table) & Xuất Phụ Đề (.SRT):**
  - Cấu trúc từng giây: *Hook 3s đầu $\to$ Trực quan bản chất $\to$ Thực chiến ví dụ $\to$ Call to action*.
  - **4 Chiến lược Hook giữ chân người xem:** *Bẫy đề thi & Cảnh báo sai lầm*, *Bản chất toán học từ số 0*, *Bí quyết giải nhanh 30s*, *Toán học kỳ diệu & Thực tế*.
  - **Xuất file phụ đề chuẩn `.SRT`:** Tự động chuyển đổi mốc thời gian và lời thoại thành phụ đề để nhập thẳng vào CapCut, Premiere Pro, DaVinci Resolve.
  - **Nghe thử Lời thoại TTS (Web Speech API):** Trình phát giọng đọc tiếng Việt tích hợp sẵn ngay trên trình duyệt để duyệt lời thoại trước khi thu âm.
- **Sinh Mã Python Manim CE Chuyên Nghiệp (8 Bộ Preset Toàn Diện):**
  - Hỗ trợ chuyên đề: *Giải tích & Đồ thị*, *Hình học không gian 3D & Oxyz xoay 360°*, *Vòng tròn lượng giác động*, *Vectơ & Tích có hướng*, *Bảng biến thiên động*, *Số phức & Mặt phẳng Argand*, *Phân phối chuẩn Gauss & Xác suất*, *Biến đổi đại số*.
  - **Tối ưu hóa Video Dọc 9:16 (TikTok / YouTube Shorts / Reels):** Tích hợp **Safe Zone** chừa 15% mép trên và 20% mép dưới tránh bị che bởi giao diện ứng dụng.
  - Tùy chọn chất lượng & khung hình: Preview nhanh (480p `-pql`), Full HD 60fps (1080p `-pqh`), 4K 60fps (`-pqk`), 30/60 FPS.

### 7. 💻 Tự Động Hóa Kịch Bản Chạy (Shell & Windows Batch)
- Hỗ trợ đầy đủ cho cả **Linux / macOS (`.sh`)** và **Windows (`.bat`)**:
  - 📥 `render_manim.sh` & `render_manim.bat`: 1-click render video Manim và tự động mở file `.mp4` sau khi render xong.
  - 📥 `compile_latex.sh` & `compile_latex.bat`: Tự động chạy `pdflatex` 2 lần, dọn dẹp file rác (`.aux`, `.log`, `.out`, `.toc`, `.synctex.gz`) và mở file PDF hoàn thiện.

## 🛠️ Cài Đặt & Chạy Ứng Dụng 1-Click

### ⚡ Chạy Ngay 1-Click (Khuyên Dùng):
- **Trên Windows:** Nhấp đúp chuột vào file **`start_app.bat`** (Tự kiểm tra Node.js, cài thư viện và tự bật trình duyệt).
- **Trên Linux / macOS:** Chạy file `./start_app.sh`

### Cách chạy thủ công qua Terminal:
```bash
# Cài đặt dependencies
npm install

# Khởi chạy hệ thống tự động hóa & web app
npm start
```
Sau đó mở trình duyệt và truy cập: **`http://localhost:3000`**.


### 2. Cài đặt môi trường Manim & FFmpeg (Nếu làm Video Toán)
```bash
# Cài đặt Manim Community Edition qua pip
pip install manim

# Cài đặt FFmpeg trên Windows qua winget
winget install --id Gyan.FFmpeg -e
```

### 3. Lệnh Render Video Manim mẫu
```bash
# Render video xem trước nhanh (480p)
manim -pql scene.py MainScene

# Render video chất lượng cao (1080p 60fps)
manim -pqh scene.py MainScene
```
